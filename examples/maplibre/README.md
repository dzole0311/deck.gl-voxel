# MapLibre example

The example uses `ZarrVoxelLayer` from `deck.gl-voxel-zarr` over a MapLibre basemap. Use the timeline to step through the data or press Play. [Setup](../../README.md#run-the-example)

## Datasets

- Hurricane Helene shows hourly ERA5 cloud cover. [GeoZarr store](https://helene-voxel-329134478190-eu-central-1.s3.eu-central-1.amazonaws.com/era5-helene.zarr/fraction_of_cloud_cover/zarr.json)
- Hurricane Milton shows NOAA GFS wind speed from the October 8, 2024 forecast. [Dynamical dataset](https://dynamical.org/catalog/noaa-gfs-forecast-virtual/)
